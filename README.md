# 👾 Portfolio arcade · Gustavo Rizzo

Portfolio personal con estilo arcade retro, hecho con React + Vite.

**Ver online:** https://gurizzo.github.io/Portfolio/

## Desarrollo

```bash
npm install
npm run dev
```

Todo el contenido (datos, habilidades, proyectos, experiencia) está en `src/data.js`.

Cada push a `main` se publica automáticamente en GitHub Pages (`.github/workflows/deploy.yml`).
